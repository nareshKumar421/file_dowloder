# 🚀 CTK Browser - Quick Start Guide

Get your beautiful browser running in **2 minutes**!

---

## ⚡ Super Fast Installation

### Step 1: Install Dependencies
```bash
pip install -r requirements-ctk-browser.txt
```

### Step 2: Run the Browser
```bash
python ctk_browser.py
```

That's it! Your browser is running! 🎉

---

## 🎯 Essential Features (30 Second Tour)

### Navigate to Websites
1. **Type in the address bar**: `github.com`
2. **Press Enter** or click **Go**
3. Browser window opens with the website!

### Search the Web
1. **Type anything**: `python tutorials`
2. **Press Enter**
3. Automatically searches on Google!

### Save Bookmarks
1. Visit a website you like
2. Click the **⭐** star button
3. Enter a name and click **Add Bookmark**
4. Access it anytime from **📚** bookmarks!

### View History
1. Click the **🕐** history button
2. See all your visited pages
3. Click **Open** to revisit any page

### Switch Themes
1. Click **⚙** settings
2. Choose **Dark**, **Light**, or **System**
3. Enjoy your preferred look!

## 🎨 Quick Customization

### Want Dark Mode?
**Already enabled by default!** ✨

### Want Light Mode?
1. Click **⚙** settings
2. Select **Light** from Appearance Mode
3. Enjoy the bright interface!

### Want Different Colors?
1. Click **⚙** settings
2. Try **Green** or **Dark-Blue** themes
3. Restart to see changes

## ⌨️ Pro Tips

### Navigation Shortcuts
- **Address Bar + Enter** = Navigate/Search instantly
- **← Button** = Go back
- **→ Button** = Go forward
- **⟳ Button** = Refresh page
- **🏠 Button** = Go to Google

### Power User Tips
1. **Multiple Tabs**: Click **+** button for new tabs
2. **Quick Bookmark**: Visit page → ⭐ → Enter → Done!
3. **Search History**: Use history to find that page you forgot to bookmark
4. **Clear History**: Settings → Clear History (stay private!)

## 🆘 Quick Troubleshooting

### Browser window not opening?
**Windows users**: Install [Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
**Linux users**: Install webkit: `sudo apt install python3-gi python3-gi-cairo gir1.2-webkit2-4.0`

### Can't install dependencies?
```bash
pip install customtkinter pywebview --upgrade
```

### Theme not changing?
Restart the browser after changing color theme!
